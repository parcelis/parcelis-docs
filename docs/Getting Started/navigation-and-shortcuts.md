Move through Parcelis efficiently with the sidebar, saved display preferences, and keyboard shortcuts.

## Use the sidebar

The sidebar links to **Portfolio**, **Properties**, **Leases**, **Tenants**, **Maintenance**, **Accounting**, and **Settings**. Portfolio and Properties are active areas in the current app.

<Callout icon="📘" theme="info">
  Leases, Tenants, Maintenance, Accounting, and Settings are visible as planned product areas; they are not yet full standalone workflows.
</Callout>

## Collapse navigation

Select the sidebar collapse control to make the navigation narrower. Parcelis saves this preference in your browser.

## Choose a theme

Use the theme switcher at the bottom of the sidebar to choose light, dark, or system mode.

- With the sidebar expanded, select the separate light, dark, or system control.
- With the sidebar collapsed, select the theme icon to cycle through the modes.

Parcelis saves your theme preference in your browser.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Cmd+Shift+P` or `Ctrl+Shift+P` | Open the property drawer. |
| `/` | Focus property search on the Properties page. |
| `Cmd+Enter` or `Ctrl+Enter` | Submit the property drawer when all required fields are valid. |
