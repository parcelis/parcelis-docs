Add, find, update, archive, and remove property records from the Properties page.

## Add a property

1. Select **Property** or **Add property** to open the property drawer.
2. Enter the property address and name.
3. Choose the property type.
4. Enter the number of units.
5. Optional: Expand **Property Contact Info** and enter contact details.
6. Select **Next** to save the property.

### Required fields

- Property address
- Property name
- Property type
- Unit count

### Optional: Store property contact information

You can add an address line 2, contact name, email, phone, and contact address.

<Callout icon="📘" theme="info">
  State fields use two-letter uppercase regions. Unit count must be at least `1` when you add a property through the drawer. If you close the drawer after changing fields, Parcelis asks you to confirm before it discards unsaved work.
</Callout>

## Use the property directory

The **Properties** page is the main operating list for your portfolio. Each row can show:

- Property name, type, address, and status
- Unit count and occupancy percentage
- Monthly rent and overdue balance
- Leases expiring in the next 90 days
- Open maintenance ticket count
- Property actions

### Search properties

Enter a name, city, state, property type, or status in the search field.

### Filter properties

1. Select **Filters**.
2. Set one or more filters: property, city, state, zip code, status, minimum number of units, open maintenance requests, or archived records only.
3. Select **Apply Filters** to update the list.
4. Select **Clear Filters** to reset the directory.

The **Filters** button shows the active filter count when filters are applied.

### Expand units

For a multi-unit property, select the expand control next to its name. The expanded rows show unit-level occupancy, rent, overdue balance, lease expiration status, maintenance ticket count, and current status.

## Manage a property

Use the overflow actions menu in a property row.

### Edit a property

Select **Edit** to change property details, address, unit count, type, or contact information.

### Add notes

Select **Add Notes** to save internal operating context, such as ownership preferences, access details, renewal reminders, or property-specific instructions.

### Archive a property

Select **Archive** to hide a property from the default directory without deleting it. Find archived records by filtering for archived properties. You cannot archive a property that is already archived.

### Delete a property

Select **Delete** only when the property should be permanently removed. Parcelis asks you to confirm before deleting the record.

## Next step

Open the property from the directory to review its operational information. See [Property details](/docs/property-details).
