Use the Portfolio dashboard to assess your portfolio’s current operating picture and open the property records that need attention.

## What you can see

The dashboard summarizes:

- Portfolio occupancy across all tracked units.
- Total properties and active leasing count.
- Occupied units and total unit count.
- Monthly rent roll summary.
- Priority operational tasks.
- A compact property snapshot table.

## Review the portfolio

1. Open **Portfolio** from the sidebar. The dashboard is the default landing page.
2. Review occupancy, property, unit, leasing, and rent roll summaries to understand portfolio-wide activity.
3. Check priority operational tasks for work that needs attention.
4. Select a property name in the snapshot table to open its detail page.

## Add or find properties

1. Select **Add property** to create a property record.
2. Select **View properties** to open the full property directory.
3. Use the **Properties** page to search or filter the portfolio.

For property onboarding and directory actions, see [Manage properties](/docs/manage-properties).
