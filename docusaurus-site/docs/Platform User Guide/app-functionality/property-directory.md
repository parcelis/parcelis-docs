The Properties page is the main operating list for the portfolio.

## What the Directory Shows

- Property name, type, and address.
- Unit count and occupancy percentage.
- Monthly rent and overdue balance.
- Leases expiring in the next 90 days.
- Open maintenance ticket count.
- Property status and row actions.

## Search Properties

Use the search field to find properties by name, city, state, property type, or status.

## Filter Properties

Select **Filters** to narrow the directory by property, city, state, zip code, status, minimum unit count, open maintenance requests, or archived status.

Select **Apply Filters** to update the list or **Clear Filters** to reset it. When filters are active, the Filters button shows the active filter count.

## Expand Units

For multi-unit properties, select the expand control next to the property name. Expanded unit rows show unit-level occupancy, rent, overdue balance, lease expiration status, maintenance ticket count, and current status.

## Open Maintenance Tickets

Select a property's **open** maintenance count to open Maintenance with that property and **Open statuses**
selected. Select the count on an expanded unit row to also filter by that unit. Counts marked **Unavailable**
are not links, and unit rows without a saved unit record do not provide a unit link.

Open statuses include New, In Progress, Pending, and Scheduled. You can change the status or other filters on
Maintenance. If tickets have changed since the directory loaded, the filtered view may show no matching tickets;
adjust or clear its filters to continue.

Counts exclude archived tickets. A ticket associated with several units counts once for the property and once
for each associated unit. Tickets saved only with a unit label count against that unit within the same property.

## Overdue balances

Property, portfolio, and expanded unit overdue totals include outstanding invoices from all lease history, including
ended and archived leases. Only positive balances with a due date before today in the organization's timezone count.
Invoices due today, future charges, paid invoices, and voided invoices do not contribute. Monthly rent and occupancy
remain operational measures of current leases; historical debt does not make a unit occupied.
